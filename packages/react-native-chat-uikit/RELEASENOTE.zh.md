# Release Note

## 2.4.0

新增特性

- 新增消息上下文菜单样式，原来的样式和新增样式可选。
- 新增消息发送附件菜单样式，原来的样式和新增样式可选。

优化

- 更新 example 项目，支持 dev 模式，在 dev 模式，海外账号可以 id 和 token 登录，国内可以 id 和密码登录。
- dev 模式，需要连续点击 demo 版本号进行切换。
- 支持 eas 云构建。

## 2.3.0

新增特性

- 增加 url 预览功能
- 增加群组消息置顶功能
- 文件预览组件被移动到示例项目，并且新增支持打开常用类型文件功能

优化

- 优化消息列表，上万条消息也可以流畅滑动
- 优化基础组件提高业务组件的易用性

## 2.2.0

新增特性

- 增加文本消息输入状态，在单聊中，用户 A 输入文本，用户 B 收到用户 A 正在输入的状态。
- 新增图片和视频文件保存功能
- 新增黑名单功能
- 新增聊天页面背景图片设置功能

优化

修复问题
